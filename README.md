いつの間にやら10年も経ってた！

ABS(Asterisk Business phone Schema)はAsteriskを小型PBX(ビジホン)として使用するためのAsterisk用設定ファイル一式と操作用のWeb UIです。

Apache Web Server,php,php-mbstring,php-sqlite3が必要です。

2026/01/10  
内部処理を含めてかなり更新し、chan_sipを排除しました。またWebsocket内線の新機能を取り入れました。

AMIハンドリングのライブラリも大幅にリファクタを行いました。

これまでのABSと互換性がなくなっているため、新ブランチ1.5としました。

旧版と機能面で差異があります。旧版の機能を使っていた方は旧版をお使いください(1.0ブランチのpanel_old)。
