ABS Conpyright 2016-2025 Takao Takahashi.

ABS(Asterisk Business phone Schema)はAsteriskを小型PBX(ビジホン)として使用するためのAsterisk用設定ファイル一式と操作用のWeb UIです。

Apache Web Server,php,php-mbstring,php-sqlite3が必要です。

2025/09/09  
WebUIを一新しました。基本はダークモードでライトモードの切り替えも行えます。またページの挙動が『雑』だった点を改め、ページリロードや戻るボタンでの操作等に支障がなくなりました。  
スタイルシートに使用していたPureはもはや使用されていません。  
旧版と機能面でいくつか差異があります。旧版の機能を使っていた方は旧版をお使いください(panel_old)。
