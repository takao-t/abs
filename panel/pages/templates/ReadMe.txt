トランク設定ファイル生成用テンプレート

トランク設定はここで定義されている生成用テンプレートから特定のキーワードを置換することでつくられます。画面上の項目に対応するキーワードは以下の通りです。

(A)種別 : プルダウンでテンプレートの名前を指定しますが、JSONに指定されているプレフィクスがファイルの名前となります。

(B)トランク番号 : ここで番号を指定すると同一名称のトランクが複数作成されます。その際、各セクション名、ファイル名に 1 のように数字を付します。

(C)ドメイン/IPアドレス : ##IPADDR## と置換されます。

(D)プロキシ/ドメイン : ##PROXY## と置換されます。

(E)ユーザ名 : ##USERNAME## と置換されます。

(F)パスワード : ##PASSWORD## と置換されます。

(G)契約番号 : ##EXTEN## と置換されます。

これらの置換文字列を利用してトランク設定ファイルを生成しますので、標準の配布で添付されていない回線のテンプレートをつくりたい場合には上記のルールに従ってテンプレートファイルを作成します。
例えば auth セクションは以下のように書きます。

[##TRUNKNAME##]
type = auth
auth_type = userpass
username = ##USERNAME##
password = ##PASSWORD##

テンプレートファイルを作成したら、trunk_definitions.json ファイルにそのテンプレートの情報を書きます。

    "hgw": {
        "label": "ひかり電話(ホームゲートウェイ)",
        "prefix": "hikari-hgw",
        "template": "pjsip_trunk_hgw.tmpl",
        "acl_template": null
    },

"hgw"部分は識別子なのでユニークな名前を付けます。labelはプルダウンに表示される名称です。prefixは各トランク名(##TRUNKNAME##)で置換される「名前」です。この例であれば、トランク設定の各セクションは[hikari-hgw]となり、数字を付した場合には[hikari-hgw1]となります。
ACL設定が櫃ような場合には acl_template のところにACLのテンプレートファイルを指定します。なお、このACLでは permit= しか使えませんので注意してください(セクション等は書いてはいけない)。単純に許可したいアドレスをpermit=で書くだけです。もう少し柔軟に対応したいのですが、各エンドポイント別にACLを設けるとbaselineのACLを「全許可」にせねばならないので、baselineは全拒否にしておき、そこへ許可を足すという方法を取っているためです。なお、デフォルトのbaseline ACLにはローカルIP(192.166.0.0/16)が入っています。この部分を変更したい場合には pjsip_base_acl.conf を編集してください。
